# 我的工作台

一个**只给自己用**的个人工作台：跑在你自己电脑上，打开浏览器就能看到今天该干什么，数据存在本地文件里，不登录、不联网、不上传。

## 它解决什么问题

自由职业 / 独立创作者的一天通常散在七八个地方：待办在备忘录、选题在手机相册、客户资料在微信聊天记录、训练计划在健身 App、收入和跟进靠脑子记。信息不缺，缺的是一个**把这堆东西放在同一屏、且都属于自己**的地方。

市面上的工具通常是：要么功能单一（只做待办），要么把数据放在别人服务器上（要登录、要订阅、随时可能改规则或关停）。这个项目选了另一条路：

- **数据是你的文件**：`data/data.json`，能用记事本打开、能复制、能进 Git、能自己备份。
- **不依赖任何云服务**：没有账号体系，没有第三方 SDK，断网全功能可用。
- **不用安装、不用构建**：有 Node.js 就能跑，没有 `npm install`。

## 主要功能

九个模块，都在左侧导航里：

| 模块 | 你能做什么 |
|---|---|
| **首页总览** | 一屏看清今天：今日完成度、本周发布数、本月咨询收入、本周训练天数；今日计划可直接勾选；快速备忘 |
| **今日计划** | 加任务、设优先级/时间/所属模块、勾完成、一键顺延到明天；已完成折叠在下 |
| **自媒体** | 内容从「选题 → 制作 → 待发 → 已发」四列看板推进；发布后录播放/点赞/评论/涨粉快照；**图表看近 30 天累计播放与涨粉趋势、三平台平均播放对比** |
| **开发工作** | 「项目 → 工作项」两层；工作项看板拖拽换列、设优先级与截止日、逾期标红 |
| **咨询工作** | 客户档案（可增删改）、每次咨询的日期/时长/费用/要点/下次跟进、长期客户的阶段目标、收入按月统计与客户排行、待跟进提醒 |
| **健身计划** | 月历视角，点某天补录：练哪个部位、什么动作、几组、几次、多重；日历格用色点标出部位，下方统计本周训练天数与各部位频次 |
| **饮食计划** | 月历视角，点某天记早/午/晚/加餐与饮水杯数（只记录，不算卡路里） |
| **游戏娱乐** | 游戏库（在玩/想玩/已通关/搁置）+ 每次游玩时长，本月总时长与最常玩 |
| **数据与设置** | 数据概况、导出备份、导入恢复、清空指定模块、浅色/深色主题、周起始日 |

另外：

- 改动后 **1.5 秒自动存盘**，顶栏有保存状态（绿=已保存 / 黄=有改动 / 红=失败），也能按 `Ctrl+S` 手动存。
- 关页面或切到后台时**抢存一次**，改完立刻关也不会丢。
- 每个模块都能「加入今日计划」，但**不做反向自动同步** —— 刻意保持单向，避免改一处跳三处。

## 快速开始

需要 **Node.js 18 或更高版本**（[下载](https://nodejs.org)）。不需要 `npm install`，项目零第三方依赖。

**Windows**：双击 `启动.bat`

**macOS / Linux**：

```bash
./start.sh
```

浏览器会自动打开 `http://127.0.0.1:5178`。关掉那个黑窗口，服务就停了。

数据在 `data/data.json`。第一次启动会自动生成，里面是空的，每个页面都有引导提示。

## 数据与备份

- `data/data.json` —— 唯一权威数据文件，UTF-8 JSON，随时可以用记事本打开看。
- `data/data.json.bak` —— 上一版自动备份，每次保存后滚动更新。
- **写入是原子操作**（先写临时文件再整体替换），写一半断电不会把文件写坏。
- 设置页可以**导出备份**（生成带日期的 JSON）和**从备份恢复**，恢复前会二次确认，并自动留一份恢复前的现场。
- 如果 `data.json` 被手工改坏，启动时会明确报「数据文件损坏」并**拒绝覆盖**，你把 `.bak` 复制回去就能恢复。

**换电脑**：把整个项目目录拷过去（含 `data/`），装上 Node 就能继续用。

## 一个重要的保护：版本号

页面的改动是「整份写回」的。如果同时开着两个标签页，或者一个页面放了很久没刷新，旧页面保存时可能把新数据覆盖掉 —— 这个项目用版本号挡住了：

- 数据里带 `rev`，每次保存 +1；
- 写入时带上加载时的版本号，对不上就**拒绝写盘**并在页面顶部提示「保存已暂停」；
- 两个出口：**刷新页面**（安全，看最新数据）或 **用本页覆盖**（明确要这么做才点）；
- 导入备份走独立的强制覆盖通道。

## 技术选择

- 服务端：Node 原生 `node:http` + `node:fs`，**零第三方依赖**。
- 前端：原生 HTML / CSS / ES Modules，**无构建步骤**，改完刷新即生效。
- 图表：手写 SVG，不引图表库（CDN 在离线环境会挂）。
- 测试：Node 内置 `node:test`，也是零依赖。
- 统计口径只写一份 `public/js/stats.js`：页面显示用它，测试断言也用它 —— 不会出现「测试过了但页面数字不对」。

## 开发与测试

```bash
npm test        # 跑全部测试（59 个）
npm start       # 启动服务（或双击 启动.bat）
```

`data/*.json` 已在 `.gitignore` 里，你的真实数据不会被提交。测试用临时目录，不会碰 `data/`。

## 常见问题

**端口 5178 被占用**：换一个端口启动 `PORT=5179 npm start`，然后访问 `http://127.0.0.1:5179`。

**页面提示「数据文件损坏」**：把 `data/data.json.bak` 复制成 `data/data.json` 覆盖掉坏文件，刷新页面。坏的现场会被留成 `data.corrupted-*.json`，不会丢。

**页面提示「保存已暂停」**：说明另一个页面或标签改过数据。点「刷新页面」拿最新数据；只有确定要以当前这页为准时才点「用本页覆盖」。

**想清空重新来**：设置页可以按模块清空（需要输入模块名确认），或者直接停掉服务、把 `data/data.json` 换成一份空数据。

## 边界

- 只保证**电脑浏览器**好用，没做手机适配。
- 单机单用户，没有多设备同步、没有协作、没有权限。
- 自媒体数据靠手填，不抓平台接口。
- 没有提醒推送、没有 AI 生成选题。
